* Private Configuration Example

This file is an example template for private configuration.
Copy the relevant examples into ~site-lisp/config/private/config.el~.

#+begin_quote
Note: This file is tracked by git as an example.
Your actual machine-local settings and secrets live in
~site-lisp/config/private/config.el~, which is ignored by git.
#+end_quote

** Startup Configuration

#+begin_src emacs-lisp
;;; config-example.el --- Example private configuration -*- lexical-binding: t; -*-

;;; ============================================================
;;; Startup Configuration
;;; ============================================================

;; Initial frame colors
;; These colors are applied from early-init before the theme is loaded,
;; reducing the white flash on Windows GUI startup. Defaults match ef-dream.
;; For the very first frame, change the defaults in config-org/early-init.org
;; and run `make all`.
;; (setq mcg-initial-frame-background "#232025")
;; (setq mcg-initial-frame-foreground "#efd5c5")

;; Startup loading strategy
;; Module loading strategy is declared in config-org/init.org with `:load'.
;; Supported values are:
;;   immediate - load before private config
;;   idle      - load after the first frame when Emacs is idle
;;   deferred  - load on file trigger from `mcg-module-triggers'
;; Example:
;;   (magit :load idle)
;;   (python :load deferred)

#+end_src
