* Private Configuration Example

This file is an example template for private configuration.
Copy this file to ~config.org~ and customize it to your needs.

#+begin_quote
Note: This file is tracked by git as an example.
Your actual configuration should be in ~config.org~, which is ignored by git.
#+end_quote
