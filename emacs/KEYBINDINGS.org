* Scope
- Global bindings are registered through the central keybinding registry.
- Mode-local bindings only work when their major/minor mode is active.
- Some idle modules expose lazy command entries, so the key is usable before
  the module itself finishes loading.
- This reference keeps global and mode-local bindings separate on purpose.
